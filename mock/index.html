1. Resumen Ejecutivo y Objetivos

Bardo es una aplicación interactiva nativa para Discord construida con la arquitectura de Cloudflare Workers + Embedded App SDK. Permite a los miembros de una comunidad colaborar en tiempo real sobre notas, documentos enriquecidos, tableros Kanban y coordinación de reuniones.

💡 Decisión Clave de Diseño: Se adoptó la paleta cromática nativa de Discord con soporte para temas Oscuro y Medianoche, mejorando la ergonomía visual y reduciendo la fricción dentro del cliente de Discord.
